# Mine Ting – webapp

Første fungerende Next.js-versjon for Vercel.

- Registrer gjenstander manuelt eller med kamera/bilde
- Lagre sted, detaljert plassering, merke/modell, tilstand, verdi, serienummer og notater
- Søk i alle gjenstander
- Administrer steder
- Lag FINN-klar annonsetekst
- Eksporter/importer sikkerhetskopi

Denne første versjonen lagrer data lokalt i nettleseren. Neste steg er konto + database slik at web og iOS kan dele samme data.
